# Brisa Dock 0.2

- Ventanas abiertas agrupadas por aplicación y accesos temporales.
- Punto inferior de ejecución y color de aplicación activa.
- Clic para activar/restaurar; Alt + clic para minimizar; Shift + clic para abrir de nuevo.
- Menú con ventanas individuales, minimizar, cierre normal y Mantener en el dock.
- Lectura del destino de accesos Windows `.lnk` en segundo plano.
- Identificación de navegador predeterminado y agrupación del gestor de archivos.
- Carpeta Descargas con menú de archivos recientes y acceso a papelera.
- Reordenación de accesos anclados mediante arrastre.
- Iconos vecinos se desplazan durante la ampliación.
- Apariencia clara y oscura; ampliación opcional.
- Actualizaciones visuales a intervalos de 16 ms durante actividad y 80 ms en reposo;
  esto es la programación del temporizador, no una medición de FPS reales.
- Backend experimental EWMH para KDE/X11; Wayland declara la falta de control de ventanas.

Referencia de comportamiento: https://support.apple.com/en-gb/guide/mac-help/mh35859/mac
Referencia de menús: https://developer.apple.com/design/human-interface-guidelines/dock-menus
No se han copiado recursos ni código de Apple.
